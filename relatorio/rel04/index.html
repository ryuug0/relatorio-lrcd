1 Introdução

O Brasil possui grandes diferenças populacionais entre seus estados. Enquanto algumas regiões concentram milhões de habitantes e extensas áreas urbanizadas, outras apresentam população menor e distribuição territorial mais dispersa.

Essas diferenças impactam diretamente áreas como transporte, saúde, educação, infraestrutura e planejamento público. Por isso, analisar dados populacionais ajuda a compreender melhor a organização demográfica do país.

Neste relatório, foram utilizados dados públicos do IBGE para construir gráficos e mapas utilizando a linguagem R. O objetivo é visualizar a distribuição da população entre os estados brasileiros e identificar padrões regionais de forma clara e intuitiva.

2 Obtenção dos Dados

Os dados utilizados foram obtidos através da API pública do SIDRA/IBGE, que disponibiliza indicadores oficiais produzidos pelo Instituto Brasileiro de Geografia e Estatística.

Já a malha geográfica dos estados brasileiros foi obtida diretamente do servidor geográfico do IBGE, permitindo a construção do mapa temático.

Os principais pacotes utilizados foram:

  • tidyverse
  • sidrar
  • ggplot2
  • plotly
  • sf
Código 
#########################################################
# Carregando pacotes
#########################################################

library(tidyverse)
library(sidrar)
library(plotly)
library(sf)

#########################################################
# Obtendo dados do SIDRA
#########################################################

pop <- get_sidra(
  x = 6579,
  variable = 9324,
  geo = "State",
  period = "last"
)

#########################################################
# Tratamento dos dados
#########################################################

pop <- pop |>
  
  rename(
    estado = `Unidade da Federação`,
    code_state = `Unidade da Federação (Código)`,
    populacao = Valor
  ) |>
  
  mutate(
    code_state = as.numeric(code_state),
    populacao = as.numeric(populacao)
  )

#########################################################
# Criando regiões
#########################################################

pop <- pop |>
  
  mutate(
    regiao = case_when(
      code_state %in% c(11,12,13,14,15,16,17)
      ~ "Norte",
      
      code_state %in% c(21,22,23,24,25,26,27,28,29)
      ~ "Nordeste",
      
      code_state %in% c(31,32,33,35)
      ~ "Sudeste",
      
      code_state %in% c(41,42,43)
      ~ "Sul",
      
      TRUE ~ "Centro-Oeste"
    )
  )

#########################################################
# Criando variável auxiliar
#########################################################

media_brasil <- mean(pop$populacao)

pop <- pop |>
  
  mutate(
    acima_media =
      ifelse(
        populacao > media_brasil,
        "Acima da média",
        "Abaixo da média"
      )
  )

#########################################################
# Obtendo malha territorial do IBGE
#########################################################

url_malha <- paste0(
  "/vsizip//vsicurl/",
  "https://geoftp.ibge.gov.br/",
  "organizacao_do_territorio/",
  "malhas_territoriais/",
  "malhas_municipais/",
  "municipio_2022/",
  "Brasil/",
  "BR/",
  "BR_UF_2022.zip"
)

estados <- st_read(
  url_malha,
  quiet = TRUE
)

#########################################################
# Ajustando código da malha
#########################################################

estados <- estados |>
  
  mutate(
    code_state = as.numeric(CD_UF)
  )

#########################################################
# Join entre dados e malha
#########################################################

mapa <- estados |>
  
  left_join(
    pop,
    by = "code_state"
  )

3 Tratamento dos Dados

Após a coleta dos dados, foi necessário organizar e padronizar algumas variáveis para facilitar as análises gráficas.

Os códigos dos estados foram convertidos para formato numérico para permitir a junção com a malha geográfica do IBGE. Também foi criada uma variável indicando se o estado possui população acima ou abaixo da média nacional.

Além disso, os estados foram agrupados por regiões brasileiras, permitindo comparações regionais ao longo do relatório.

5 Comparação entre Base R e ggplot2

5.1 Base R

O Base R permite criar gráficos de maneira rápida e simples.

Código 
barplot(
  pop$populacao,
  
  names.arg = pop$estado,
  
  col = "tomato",
  
  las = 2,
  
  main = "População dos Estados - Base R"
)

5.2 ggplot2

O ggplot2 oferece maior flexibilidade visual e melhor organização estética.

Código 
ggplot(
  pop,
  aes(
    estado,
    populacao
  )
) +
  
  geom_col(fill = "tomato") +
  
  labs(
    title = "População dos Estados - ggplot2",
    x = "Estado",
    y = "População"
  ) +
  
  theme_classic() +
  
  theme(
    axis.text.x = element_text(
      angle = 90
    )
  )

5.3 Comparação

Os dois sistemas conseguem produzir gráficos eficientes, mas possuem propostas diferentes.

O Base R é mais direto e simples para análises rápidas. Já o ggplot2 facilita a personalização visual e produz gráficos mais organizados e modernos.

Para relatórios e apresentações, o ggplot2 acaba sendo mais vantajoso pela estética e flexibilidade.

6 Interpretação dos Resultados

Os gráficos mostram que a população brasileira está concentrada principalmente nos estados do Sudeste, especialmente em São Paulo e Minas Gerais.

Já estados da região Norte apresentam populações menores e distribuição mais dispersa.

O histograma indica que poucos estados possuem populações muito elevadas, enquanto a maioria se concentra em faixas intermediárias.

O boxplot também evidencia diferenças importantes entre as regiões brasileiras, principalmente entre Sudeste e Norte.

O mapa temático foi um dos gráficos mais úteis, pois permitiu visualizar essas diferenças de maneira espacial e intuitiva.

7 Conclusão

A utilização da linguagem R permitiu transformar dados públicos em visualizações claras e informativas.

Os gráficos facilitaram a identificação de padrões populacionais e diferenças regionais entre os estados brasileiros.

Entre as visualizações produzidas, o gráfico de barras e o mapa temático foram os mais eficientes para interpretação dos dados.

Além disso, o trabalho mostrou como o R pode ser utilizado para coleta, tratamento e visualização de dados reais obtidos através de APIs públicas.
